# 展開図クイズ

完成した立方体・直方体を見て、正しい展開図を4択から選ぶ学習用Webアプリです。正解・不正解のどちらでも、展開図が折りたたまれる様子を確認できます。

バージョン：`0.1.0-dev3`

## 起動方法

`index.html` をブラウザで直接開いてください。インストールや通信は不要です。

## モードと操作

- 初級：立方体のみ
- 中級：直方体のみ
- 上級：立方体と直方体を混合
- 問題数は5問・10問・20問から選択
- 選択肢はクリック、タップ、Enter、Spaceで回答可能
- 展開図は座標範囲から表示領域を自動計算するSVGで描画
- 折りたたみは、親面・共有辺・回転方向を使ったJavaScriptの3D計算とSVG polygonで表示
- 4×4変換行列で親面の変換を子面へ再帰的に継承し、共有辺を保ったまま折りたたみ
- 完成状態は8頂点・12辺・6面、寸法、共有辺、6方向の法線を自動検証
- 完成時は裏面を非表示にし、カメラから遠い面から描画
- アニメーションは再生、一時停止、先頭へ戻る、位置スライダーに対応
- 結果画面から間違えた問題だけを復習可能
- ふりがな、効果音、全画面表示を画面上部で切り替え可能

## 対応環境

最新版のChrome、Edge、Firefox、Safari。スマートフォン・タブレット・PCの画面幅に対応します。

## プライバシーとオフライン動作

外部通信、Cookie、localStorageは使用しません。個人情報や学習履歴を保存せず、再読み込みすると初期状態へ戻ります。
